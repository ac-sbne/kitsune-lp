## GitHub Pages 公開手順

1. この `lp-kitsune` フォルダをリポジトリにpush
2. GitHub の `Settings` > `Pages`
3. `Branch` を選択（例: `main` / `/lp-kitsune` またはルート）
4. 保存して公開URLを確認
