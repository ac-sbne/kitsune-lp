# kitsune-lp (GitHub Pages)

既存の kitsune-lp をベースにした、4ページ構成のミニマルサイトです。

## ページ構成

- `index.html` - Home（最新商品 + 最新note）
- `create-item.html` - Create Item（LP一覧）
- `information.html` - Information（note一覧）
- `contact.html` - Contact（Gmail受信フォーム）
- `styles.css` - 全ページ共通スタイル

## 反映済みリンク

- note: `https://note.com/ac_sbne`
- BASE: `https://acsbnec.base.shop/`

## Contactフォーム設定

`contact.html` は無料の `FormSubmit` で設定済みです。

- 送信先: `acsbne.company@gmail.com`
- 初回送信時は FormSubmit の確認メールで承認が必要

## GitHub Pages 公開手順

1. リポジトリ `ac-sbne/kitsune-lp` に push
2. GitHub の `Settings` > `Pages`
3. `Branch` を `main`（または公開対象ブランチ）に設定
4. 保存して公開URLを確認
